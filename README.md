ClinicaMed: A dedicated application for managing the activities of a medical clinic, featuring the following core functionalities:

Medical Entity and Data Management (JPA): Models and stores essential information in the database, such as patients, doctors, appointments, consultations, or medical services.

Web Interface and User Interaction (Web): Provides a web component that enables users (patients or clinic staff) to navigate and access the system's functionalities.

Workflow Automation: Manages clinic-specific processes, such as scheduling consultations, maintaining patient records, and handling the connection between patients and medical staff.
